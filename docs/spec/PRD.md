# PRD — 클래스보드(ClassBoard) 제품 요구사항 문서

> "클래스보드"는 임시 이름이다. 바꾸려면 세 문서(PRD, TRD, TASK)에서 함께 바꾼다.

## 1. 개요

클래스보드는 교사나 발표자가 수업 중 교실 화면(빔프로젝터, 전자칠판)에 띄워 두고 쓰는 위젯 기반 웹앱이다. Classroomscreen과 같은 종류의 도구이며, 폴리텍대학 바이브코딩 웹앱 제작 수업의 실습 프로젝트로 만든다.

- 한 화면에 배경을 깔고, 필요한 위젯을 꺼내 원하는 자리에 배치한다.
- 회원가입, 로그인, 서버 없이 브라우저에서 바로 실행된다.
- 이 문서의 범위는 웹앱을 완성하는 데까지다. GitHub 업로드와 배포는 완성 후 따로 진행한다.

## 2. 목표와 성공 기준

| 목표 | 성공 기준 |
|---|---|
| 수업에 바로 쓸 수 있는 화면 | 8개 위젯이 모두 4장의 완료 기준을 통과한다 |
| 다시 열어도 그대로 | 새로고침 후에도 배경, 위젯 위치, 입력 내용이 유지된다 |
| 교실 뒤에서도 보임 | 1920×1080 화면에서 타이머 숫자와 뽑힌 이름이 화면 높이의 8% 이상 크기로 보인다 |
| 오류 없는 실행 | `index.html`을 열었을 때 개발자 도구 콘솔에 빨간 오류가 없다 |

## 3. 사용자와 사용 장면

**주 사용자**: 초·중·고 교사, 대학 강사, 퍼실리테이터 등 교실 앞 PC나 전자칠판으로 수업을 진행하는 사람.

**사용 장면**

1. 수업 시작 전: 앱을 열면 지난번에 배치한 화면이 그대로 나온다.
2. 활동 시간: 타이머를 5분으로 맞추고 시작한다. 끝나면 소리와 깜빡임으로 알려 준다.
3. 발표자 정하기: 제비뽑기로 학생 한 명 또는 여러 명을 무작위로 뽑는다.
4. 분위기 조절: 활동 상태를 "조용히"로 바꿔 보여 준다.
5. 설명하기: 그림판에 간단한 그림을 그리고, 메모장에 오늘의 과제를 적어 둔다.
6. 게임과 순서 정하기: 주사위를 굴리고, 스톱워치로 걸린 시간을 잰다.

## 4. 기능 요구사항

### 4.1 공통 화면 (F-00)

| 번호 | 요구사항 | 완료 기준 |
|---|---|---|
| F-00-1 | 화면 전체가 배경(스테이지)이고 하단 가운데에 도구 모음이 있다 | 스크롤바가 생기지 않는다 |
| F-00-2 | 도구 모음에는 위젯 버튼 8개, 전체 화면 버튼, 모두 초기화 버튼이 있다 | 각 버튼에 아이콘과 한글 이름이 보인다 |
| F-00-3 | 위젯 버튼을 누르면 해당 위젯 카드가 열리고, 다시 누르면 닫힌다 | 열린 위젯의 버튼은 강조 표시된다 |
| F-00-4 | 위젯 카드는 제목 줄과 닫기(×) 버튼을 가진다 | ×로 닫으면 도구 모음 강조도 꺼진다 |
| F-00-5 | 제목 줄을 끌어 카드를 옮길 수 있다 | 마우스와 터치 모두 동작하고, 카드가 화면 밖으로 나가지 않는다 |
| F-00-6 | 카드를 누르면 맨 앞으로 올라온다 | 겹친 카드 중 누른 카드가 위에 보인다 |
| F-00-7 | 배경, 열린 위젯, 위치, 입력 내용이 자동 저장된다 | 새로고침 후 같은 화면이 복원된다 |
| F-00-8 | 전체 화면 버튼으로 전체 화면을 켜고 끈다 | Esc로도 해제되고 버튼 표시가 맞게 바뀐다 |
| F-00-9 | 모두 초기화 버튼은 저장된 내용을 지우고 처음 상태로 돌린다 | 두 번 눌러야 실행된다(브라우저 알림창 사용 안 함) |
| F-00-10 | 창 크기가 바뀌면 화면 밖에 걸친 카드가 안쪽으로 들어온다 | 창을 줄여도 모든 카드의 제목 줄을 잡을 수 있다 |

위젯은 종류마다 하나씩만 열 수 있고 카드 크기는 고정이다. 실행 중이던 타이머, 스톱워치는 새로고침하면 정지 상태로 돌아간다.

### 4.2 배경 위젯 (F-01)

- 미리 준비된 배경 8종(단색 4종, 그라데이션 4종) 중 하나를 고른다. 이미지 파일은 쓰지 않는다.
- 누르는 즉시 화면 배경이 바뀌고, 현재 선택된 배경에 테두리 표시가 된다.
- 어떤 배경에서도 위젯 카드의 글자가 읽힌다(카드는 자체 배경색을 가진다).

**완료 기준**: 8종 모두 적용되고, 새로고침 후 선택한 배경이 유지된다.

### 4.3 타이머 위젯 (F-02)

- 분(0~99)과 초(0~59)를 입력한다. 빠른 설정 버튼 1분, 3분, 5분, 10분이 있다.
- 시작, 일시정지, 초기화 버튼이 있다. 남은 시간은 `MM:SS`로 크게 표시한다.
- 남은 시간이 10초 이하면 숫자 색이 경고색으로 바뀐다.
- 0이 되면 알림음이 3번 울리고 카드가 깜빡인다. 아무 버튼이나 누르면 멈춘다.
- 실행 중에는 시간 입력을 바꿀 수 없다.
- 다른 탭을 보다 돌아와도 실제 시간과 어긋나지 않는다.

**완료 기준**: 1분 타이머가 실제 60초(±1초)에 끝나고 알림음이 울린다. 0분 0초로는 시작되지 않는다. 숫자가 아닌 입력과 범위를 넘는 값은 허용 범위로 보정된다.

### 4.4 스톱워치 위젯 (F-03)

- 시작, 일시정지, 초기화 버튼이 있다. 경과 시간은 `MM:SS.cc`(분:초.1/100초)로 표시한다.
- 랩 버튼을 누르면 그 순간의 기록이 목록에 추가된다. 각 줄에 번호, 구간 시간, 누적 시간을 보여 준다.
- 랩 목록은 최신 기록이 위에 오고, 길어지면 카드 안에서 스크롤된다. 최대 30개까지 기록한다.
- 랩 버튼은 실행 중일 때만 누를 수 있다. 초기화하면 시간과 랩 목록이 모두 지워진다.

**완료 기준**: 휴대폰 스톱워치와 동시에 시작해 30초 뒤 차이가 1초 이내다. 일시정지 후 다시 시작하면 이어서 올라간다. 랩 3번을 누르면 구간 시간 3개의 합이 마지막 누적 시간과 같다.

### 4.5 제비뽑기 위젯 (F-04)

- 이름 목록을 한 줄에 한 명씩 입력한다. 빈 줄과 앞뒤 공백은 무시한다.
- 한 번에 뽑을 인원(1~5명)을 정한다. 한 번의 추첨에서 같은 사람이 두 번 나오지 않는다.
- 추첨 버튼을 누르면 약 1.5초 동안 이름이 빠르게 바뀌다가 당첨자가 크게 표시된다.
- "뽑힌 사람 제외" 옵션을 켜면 이미 뽑힌 사람은 다시 나오지 않는다. 남은 인원 수를 보여 준다.
- 남은 인원이 뽑을 인원보다 적으면 남은 사람을 모두 뽑는다.
- "다시 채우기" 버튼으로 제외된 사람을 모두 되돌린다.
- 목록이 비어 있으면 "이름을 먼저 입력하세요", 모두 뽑혔으면 "모두 뽑았어요" 안내를 보여 준다.

**완료 기준**: 5명을 넣고 제외 옵션을 켠 채 2명씩 뽑으면 2명, 2명, 1명 순서로 5명이 한 번씩 나오고, 네 번째에는 "모두 뽑았어요"가 나온다. 이름 목록과 옵션은 새로고침 후에도 유지된다.

### 4.6 주사위 위젯 (F-05)

- 주사위 개수를 1개 또는 2개로 고른다.
- 굴리기 버튼을 누르면 약 1초 동안 눈이 빠르게 바뀌다가 멈춘다.
- 주사위 면은 숫자가 아니라 점(1~6개)으로 그린다.
- 2개일 때는 합계를 함께 보여 준다.
- 굴리는 중에는 버튼이 눌리지 않는다.

**완료 기준**: 20번 굴렸을 때 모든 결과가 1~6이고 여러 값이 섞여 나온다. 2개일 때 합계가 두 눈의 합과 같다. 개수 선택이 새로고침 후에도 유지된다.

### 4.7 메모장 위젯 (F-06)

- 여러 줄 글을 입력한다. 입력하는 대로 자동 저장된다.
- 글자 크기를 작게, 보통, 크게 3단계로 바꾼다.
- 글자 색을 검정, 빨강, 파랑, 초록 4가지 중에서 고른다.
- 지우기 버튼으로 내용을 비운다.

**완료 기준**: 입력한 글, 크기, 색이 새로고침 후에도 유지된다. `<b>굵게</b>` 같은 글을 넣어도 태그가 그대로 글자로 보인다.

### 4.8 그림판 위젯 (F-07)

- 마우스나 손가락으로 선을 그린다.
- 펜 색 6가지(검정, 빨강, 파랑, 초록, 노랑, 보라)와 굵기 3단계(가늘게, 보통, 굵게)를 고른다.
- 지우개를 고르면 지나간 자리가 지워진다.
- 모두 지우기 버튼은 두 번 눌러야 실행된다.
- 그린 그림은 자동 저장된다.

**완료 기준**: 빠르게 그어도 선이 끊기지 않고 이어진다. 기기 모드(터치)에서 그릴 때 화면이 스크롤되지 않는다. 그림을 그리는 동안 카드가 끌려가지 않는다. 그림이 새로고침 후에도 남아 있다.

### 4.9 활동 상태 위젯 (F-08)

- 네 가지 상태 중 하나를 고른다: 🤫 조용히, 💬 소곤소곤, 👥 모둠 활동, 🙋 질문하기.
- 고른 상태의 아이콘과 글자가 카드에 크게 표시된다.
- 고른 상태를 다시 누르면 선택이 풀리고 "상태를 선택하세요"가 나온다.

**완료 기준**: 한 번에 하나만 선택되고, 선택이 새로고침 후에도 유지된다. Tab과 Enter만으로 상태를 바꿀 수 있다.

## 5. 비기능 요구사항

| 구분 | 요구사항 |
|---|---|
| 지원 환경 | 최신 Chrome, Edge. 화면 1024×768 이상(모니터, 빔프로젝터, 가로로 둔 태블릿). 마우스와 터치 지원 |
| 성능 | 첫 화면이 2초 안에 뜬다. 카드를 끌거나 그림을 그릴 때 끊김이 없다 |
| 개인정보 | 이름 목록 등 모든 데이터는 사용자의 브라우저에만 저장하고 외부로 보내지 않는다 |
| 접근성 | 모든 버튼을 키보드(Tab, Enter)로 조작할 수 있고, 아이콘 버튼에는 설명 문구가 있다 |
| 의존성 | 외부 라이브러리, CDN, 외부 글꼴, 이미지·소리 파일을 쓰지 않는다 |
| 언어 | 화면 문구는 모두 한국어 |
| 독자성 | Classroomscreen의 이름, 로고, 디자인, 아이콘을 베끼지 않고 자체 디자인으로 만든다 |

## 6. 범위에서 제외 (이번에는 만들지 않음)

시계, 신호등, 소음 측정기, QR 코드, 배경 이미지 올리기, 위젯 크기 조절, 같은 위젯 여러 개 열기, 로그인과 서버 저장, 스마트폰 세로 화면 대응, GitHub 업로드와 배포.

## 7. 최종 인수 조건

1. `index.html`을 열었을 때 오류 없이 화면이 뜬다(콘솔에 빨간 오류 없음).
2. 4장의 모든 완료 기준을 통과한다.
3. 저장 내용을 모두 지운 "처음 방문" 상태에서도 정상 동작한다.
4. README.md에 프로젝트 소개, 실행 방법, 위젯별 사용법이 들어 있다.
