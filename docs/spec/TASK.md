# TASK — 클래스보드(ClassBoard) 작업 목록

PRD.md(무엇을)와 TRD.md(어떻게)를 실제 작업 순서로 나눈 문서다. 위에서 아래로 순서대로 진행한다. 범위는 웹앱 완성까지이고, GitHub 업로드와 배포는 모든 작업이 끝난 뒤 따로 진행한다.

## 진행 방법

1. **한 번에 TASK 하나만** 시킨다. 예: "docs/spec 폴더의 PRD.md, TRD.md, TASK.md를 읽고 T1-1만 진행해 줘. 끝나면 확인 방법을 알려 줘."
2. 작업이 끝나면 아래 "확인"을 브라우저에서 직접 해 본다.
3. 통과하면 체크 표시(`[x]`)를 하고 `docs/spec/LOG.md`에 기록을 남긴 뒤 다음 TASK로 간다.
4. 통과하지 못하면 어떤 확인 항목이 어떻게 안 되는지 그대로 알려 주고 고치게 한다. 다음 TASK로 넘어가지 않는다.
5. 문서와 다르게 만들고 싶어지면 문서를 먼저 고친 뒤 작업을 시킨다.

모든 TASK에 공통인 확인: 개발자 도구(F12) 콘솔에 빨간 오류가 없다.

## 1단계 — 뼈대

- TRD 2장의 폴더 구조대로 빈 파일을 만든다.

**확인**: 화면 전체에 배경이 차고 하단 가운데에 빈 도구 모음이 보인다. 스크롤바가 없다.

### [x] T1-2 저장 모듈

- `storage.js`: `App.storage.load()`, `save(state)`, `reset()` (TRD 3.3).

**확인**: 콘솔에서 `App.storage.save({background:'test', zTop:1, widgets:{}})` 후 새로고침하고 `App.storage.load()`를 하면 같은 값이 나온다. Local Storage의 값을 `abc`로 망가뜨리고 새로고침해도 오류 없이 기본 상태가 나온다.

### [x] T1-3 위젯 등록과 카드, 도구 모음

- `app.js`: `App.registerWidget`, `App.init`, `openWidget`, `closeWidget`, `toggleWidget`, 카드 생성(제목 줄, × 버튼, 본문).
- 도구 모음 버튼은 등록된 위젯 목록에서 자동으로 만든다.
- 확인용으로 본문에 글자만 있는 임시 위젯 `test`, `test2`를 등록한다.

**확인**: 임시 위젯 버튼을 누르면 카드가 열리고 버튼이 강조된다. 다시 누르거나 ×를 누르면 닫히고 강조가 꺼진다. 같은 위젯이 두 개 열리지 않는다. 연 채로 새로고침하면 열린 상태가 복원된다. (PRD F-00-2, 3, 4, 7)

### [x] T1-4 카드 끌기

- `drag.js`: TRD 4.2 그대로 구현하고 카드에 연결한다.
- 카드를 누르면 맨 앞으로, 창 크기 변경 시 화면 안으로.

**확인**: 제목 줄을 끌어 카드를 옮길 수 있고 화면 밖과 도구 모음 위로 나가지 않는다. 겹친 두 카드 중 누른 카드가 위로 온다. 옮긴 뒤 새로고침하면 같은 자리에 있다. 기기 모드(터치)에서도 끌린다. 창을 줄이면 카드가 안쪽으로 들어온다. (PRD F-00-5, 6, 10)

### [x] T1-5 전체 화면과 모두 초기화

- `App.confirmButton` 구현(TRD 4.3).
- 도구 모음에 전체 화면, 모두 초기화 버튼을 추가한다(TRD 4.11).

**확인**: PRD F-00-8, F-00-9. 초기화 버튼을 한 번만 누르고 3초 기다리면 원래 문구로 돌아오고 아무것도 지워지지 않는다.
