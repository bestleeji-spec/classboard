# 클래스보드 (ClassBoard)

수업 중 교실 화면(빔프로젝터, 전자칠판)에 띄워 두고 쓰는 위젯 기반 웹앱입니다.
배경을 고르고 타이머, 제비뽑기, 그림판 같은 위젯을 꺼내 원하는 자리에 놓고 씁니다.

- 회원가입, 로그인, 서버 없이 브라우저에서 바로 실행됩니다.
- 화면 배치와 입력한 내용은 자동으로 저장되어, 다음에 열어도 그대로 나옵니다.
- 모든 데이터는 사용하는 브라우저 안에만 저장되고 외부로 보내지 않습니다.

## 실행 방법

1. 프로젝트 폴더를 내려받습니다.
2. `index.html`을 더블클릭해 Chrome 또는 Edge로 엽니다.
   - VS Code를 쓴다면 Live Server 확장으로 열어도 됩니다.
3. 설치나 빌드 과정은 없습니다.

**권장 환경**: 최신 Chrome, Edge / 화면 1024×768 이상(모니터, 빔프로젝터, 가로로 둔 태블릿) / 마우스와 터치 모두 지원

## 기본 사용법

화면 아래 가운데의 **도구 모음**에서 모든 기능을 씁니다.

| 동작 | 방법 |
|---|---|
| 위젯 열기·닫기 | 도구 모음의 위젯 버튼을 누릅니다. 열린 위젯의 버튼은 파랗게 강조됩니다. 카드의 × 버튼으로도 닫을 수 있습니다. |
| 위젯 옮기기 | 카드의 제목 줄을 끌어 옮깁니다. 마우스와 손가락 모두 됩니다. |
| 맨 앞으로 | 겹친 카드 중 아무 곳이나 누르면 그 카드가 맨 앞으로 올라옵니다. |
| 전체 화면 | 🖥️ **전체 화면** 버튼을 누릅니다. 다시 누르거나 Esc를 누르면 해제됩니다. |
| 처음 상태로 | 🧹 **모두 초기화**를 누르면 "정말 지울까요?"로 바뀝니다. 3초 안에 한 번 더 눌러야 실행됩니다. |

- 위젯은 종류마다 하나씩 열 수 있고, 카드 크기는 고정입니다.
- 실행 중이던 타이머와 스톱워치는 새로고침하면 멈춘 상태로 돌아갑니다.
- 모든 버튼은 키보드(Tab으로 이동, Enter로 누르기)로도 쓸 수 있습니다.

## 위젯별 사용법

### 🖼️ 배경
- 배경 8가지 중 하나를 누르면 화면 배경이 바로 바뀝니다.
  - 그라데이션: 하늘, 노을, 숲, 라벤더
  - 단색: 칠판, 남색, 크림, 회색
- 지금 쓰는 배경에는 파란 테두리가 표시됩니다.

### ⏳ 타이머
- 분(0~99)과 초(0~59)를 입력하거나, **1분 / 3분 / 5분 / 10분** 빠른 설정을 누릅니다.
- **시작**, **일시정지**, **초기화** 버튼으로 조작합니다. 일시정지 중에는 시작 버튼이 **계속**으로 바뀝니다.
- 남은 시간이 10초 이하가 되면 숫자가 빨간색으로 바뀝니다.
- 0이 되면 알림음이 3번 울리고 카드가 깜빡입니다. 카드 안의 아무 버튼이나 누르면 멈춥니다.
- 다른 탭을 보다 돌아와도 시간이 어긋나지 않습니다.

### ⏱️ 스톱워치
- **시작**, **일시정지**, **초기화**로 조작합니다. 시간은 `분:초.1/100초`로 표시됩니다.
- 실행 중에 **랩**을 누르면 그 순간의 기록이 목록 맨 위에 추가됩니다(번호, 구간 시간, 누적 시간).
- 랩은 30개까지 기록되고, 목록이 길어지면 카드 안에서 스크롤됩니다.

### 🎯 제비뽑기
1. 아래 입력칸에 이름을 한 줄에 한 명씩 적습니다. 빈 줄과 앞뒤 공백은 무시됩니다.
2. **인원**에서 한 번에 뽑을 사람 수(1~5명)를 고릅니다.
3. **추첨**을 누르면 약 1.5초 동안 이름이 바뀌다가 당첨자가 크게 나옵니다.

- **☑ 뽑힌 사람 제외**를 켜 두면 이미 뽑힌 사람은 다시 나오지 않습니다. 왼쪽 아래에 남은 인원이 표시됩니다.
- 모두 뽑으면 "모두 뽑았어요"가 나옵니다. **다시 채우기**를 누르면 처음부터 다시 뽑을 수 있습니다.
- 같은 이름이 두 줄 있으면 서로 다른 두 사람으로 봅니다.
- 이름 목록을 고치면 뽑힌 기록이 초기화됩니다.

### 🎲 주사위
- 주사위 개수를 **1개** 또는 **2개**로 고릅니다.
- **굴리기**를 누르면 약 1초 동안 흔들리다가 멈춥니다. 2개일 때는 합계도 보여 줍니다.

### 📝 메모장
- 오늘의 과제나 안내를 적어 둡니다. 입력하는 대로 자동 저장됩니다.
- 글자 크기(**작게 / 보통 / 크게**)와 글자 색(검정, 빨강, 파랑, 초록)을 바꿀 수 있습니다.
- **지우기**를 누르면 내용이 비워집니다.

### 🎨 그림판
- 마우스나 손가락으로 그립니다.
- 펜 색 6가지(검정, 빨강, 파랑, 초록, 노랑, 보라)와 굵기 3단계(가늘게, 보통, 굵게)를 고릅니다.
- **지우개**를 누르고 문지르면 지워집니다. 펜 색이나 굵기를 다시 고르면 펜으로 돌아옵니다.
- **모두 지우기**는 3초 안에 두 번 눌러야 실행됩니다.
- 그린 그림은 선을 하나 그을 때마다 자동 저장됩니다.

### 🤫 활동 상태
- 🤫 조용히, 💬 소곤소곤, 👥 모둠 활동, 🙋 질문하기 중 하나를 누르면 카드에 크게 표시됩니다.
- 고른 상태를 다시 누르면 선택이 풀립니다.

## 사용 기술

| 항목 | 내용 |
|---|---|
| 언어 | HTML5, CSS3, JavaScript(ES2020) |
| 프레임워크·라이브러리 | 사용하지 않음 (외부 CDN, 외부 글꼴, 이미지·소리 파일도 없음) |
| 저장 | 브라우저 `localStorage` (키 `classboard:v1`) |
| 소리 | Web Audio API (알림음을 코드로 만듦) |
| 그림 | Canvas 2D API |
| 끌기·그리기 | Pointer Events (마우스와 터치를 한 번에 처리) |
| 아이콘 | 이모지 |
| 개발 도구 | Visual Studio Code, Claude |

## 폴더 구조

```
├─ index.html
├─ README.md
├─ CLAUDE.md               # Claude에게 주는 프로젝트 규칙 요약
├─ css/
│  ├─ style.css            # 전체 레이아웃, 색 변수, 도구 모음, 카드 공통
│  └─ widgets.css          # 위젯별 스타일
├─ js/
│  ├─ storage.js           # 저장·불러오기
│  ├─ drag.js              # 카드 끌기
│  ├─ app.js               # 위젯 등록, 카드·도구 모음 생성
│  ├─ widgets/             # 위젯 8개(배경, 타이머, 스톱워치, 제비뽑기, 주사위, 메모장, 그림판, 활동 상태)
│  └─ main.js              # 앱 시작
└─ docs/spec/
   ├─ PRD.md               # 제품 요구사항(무엇을)
   ├─ TRD.md               # 기술 요구사항(어떻게)
   ├─ TASK.md              # 작업 목록(순서)
   └─ LOG.md               # 작업 기록
```
